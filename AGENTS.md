# Инструкции для Codex

Ты работаешь над мобильной игрой Dante и её лендингом.

## Язык общения

Всегда используй русский язык:

- Pull Request описания — на русском
- Commit сообщения — на русском
- Issues — на русском
- комментарии и объяснения — на русском

Исключение:
- названия файлов
- имена компонентов
- переменные
- технические API названия

## Стек проекта

- React
- Vite
- JavaScript
- CSS
- GitHub Pages

## Правила разработки

- Не меняй внешний вид без отдельной задачи
- Не ломай существующую структуру
- Один PR = одна задача
- Не смешивай разные изменения

Перед завершением задачи всегда запускай:

npm run format
npm run lint
npm run build

Все проверки должны проходить успешно.

## Архитектура

Использовать структуру:

src/components — React компоненты

src/data — данные игры

src/styles — стили

Компоненты создавать через:

export default function ComponentName()

## После выполнения задачи

Всегда указывай:

1. Что изменено
2. Какие файлы затронуты
3. Какие проверки выполнены
4. Какие дальнейшие шаги рекомендуются
